PSVITADEV Pacman

This is the repository for the package manager for the Playstation Vita SDK called PSVITADEV.

Packages can be installed using the following command: 

# psv-pacman -Sy package-name
Updating installed packages can be done using the following command: 
# psv-pacman -Syu

To download PSVITADEV Pacman pick the download link below for your platform:
  • alpine_x86_64
  • debian_x86_64
  • fedora_x86_64
  • macos_arm64
  • macos_x86_64
  • ubuntu_aarch64
  • ubuntu_x86_64

After downloading, set the following variables in the command line to make it usable: 

# export PSVITADEV="psvitadev"
# export PATH="${PATH}:${PSVITADEV}/bin"
Replace "psvitadev" with the full path to the extracted psvitadev directory. The export commands can also be added to "~/.bashrc" on Linux or "~/.zprofile" on MacOS to make them available permanently. On Windows, use Ubuntu in WSL to use this package.
